強度係數 IF：一個數字說完「今天騎得多硬」

IF 等於 NP 除以 FTP。0.65 是恢復騎，0.85 是紮實的節奏騎，1.0 是一小時全力。學會看 IF，你就能快速判斷一趟騎乘的性質。

本篇章節（3）
  1. 各數值大致對應
  2. 為什麼 IF 好用
  3. 三個實務用法

IF（Intensity Factor，強度係數）＝ 正規化功率 NP ÷ FTP。 它把功率換算成「相對於你自己的強度」，所以不同能力的車手可以互相比較。

各數值大致對應#

  • < 0.65：恢復騎
  • 0.65–0.75：有氧耐力長騎
  • 0.75–0.85：節奏騎、Sweet Spot
  • 0.85–0.95：閾值課表、較長的計時賽（40 km 以上）
  • 0.95–1.05：一小時左右的計時賽或非常激烈的比賽
  • > 1.05：短時間的爆發性賽事（爬坡賽、繞圈賽）

為什麼 IF 好用#

因為它自動幫你正規化了能力差異。你 FTP 220 W、車友 320 W，兩人同一場團騎回來，比較 IF 就知道誰騎得比較吃力——這比比較瓦特數有意義得多。

三個實務用法#

一、檢查恢復日有沒有真的恢復。 恢復騎的 IF 應該在 0.6 以下。超過 0.7，那不是恢復，是低強度訓練。

二、比賽後回頭校正 FTP。 如果一場一小時的計時賽算出 IF 是 1.08，代表你的 FTP 被低估了；反過來只有 0.90，可能是 FTP 設太高，或你的配速有問題。

三、預估一趟課表的負荷。 TSS ≈ 時數 × IF² × 100。所以 2 小時 IF 0.8 的騎乘 ≈ 128 TSS。IF 的影響是平方的——強度稍微提高，負荷就大幅上升。

時間會騙人，距離也會。IF 直接告訴你，這趟騎乘離你的極限有多近。
