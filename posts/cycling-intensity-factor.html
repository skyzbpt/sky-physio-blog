強度係數 IF：一個數字說完「今天騎得多硬」

IF 等於 NP 除以 FTP。0.65 以下是恢復騎，0.85 是紮實的節奏騎，1.0 是一小時全力。學會看 IF，你就能快速判斷一趟騎乘的性質。

「今天騎了兩小時、七十公里，這樣算硬嗎？」車友常這樣問我。老實說，光看時間和距離答不出來：同樣七十公里，順風平路和逆風爬坡是兩回事；同樣兩小時，跟著快車隊衝和自己慢慢晃，也是兩回事。

IF（Intensity Factor，強度係數）＝ 正規化功率 NP ÷ FTP（功能性閾值功率）。 它把功率換算成「相對於你自己的強度」，所以不同能力的車手可以互相比較，你也能把今天的自己和三個月前放在同一把尺上。

用「油門踩了幾成」來理解強度係數#

想像兩台車都開時速一百：小排氣量的車油門可能要踩到七成，跑車只要踩三成。速度一樣，引擎吃力的程度完全不同。

IF 就是你今天的油門開度，刻度的基準是 FTP（大約能穩定撐一小時的最大功率）。要注意，1.0 不是油門踩到底，而是你大約能穩穩踩住一小時的深度；比賽越短，IF 越有機會超過 1.0。

所以兩個人同一場團騎回來：小陳 FTP 220 W、NP 200 W，IF 是 0.91；阿凱 FTP 320 W、NP 240 W，IF 只有 0.75。阿凱多踩了 40 W，但真正騎到接近閾值、隔天該休息的是小陳。比較 IF，遠比比較瓦特數有意義。

一步一步算一次強度係數#

IF 的分子是 NP，不是平均功率。NP 的算法是先取 30 秒移動平均，每個值做四次方、再平均、最後開四次方根，用意是讓衝坡、加速這些高功率片段「算得重一點」，細節在 NP 那篇。軟體會自動算，你只要知道它從哪裡來。

舉一個你可以自己驗算的例子。一位 FTP 250 W 的車友，騎了一趟兩小時的丘陵路線：

  1. 碼表顯示平均功率 185 W、NP 210 W
  2. 如果用平均功率看：185 ÷ 250 ＝ 0.74，像一趟輕鬆的耐力騎
  3. 用 NP 算：IF ＝ 210 ÷ 250 ＝ 0.84，其實是一趟紮實的節奏騎
  4. TSS（訓練量分數）＝ 時數 × IF² × 100 ＝ 2 × 0.84² × 100 ≈ 141

TSS 的原始公式是「秒數 × NP × IF ÷（FTP × 3600）× 100」，因為 NP ÷ FTP 就是 IF，化簡後就是上面那條。

再看 IF 的平方效應：同樣兩小時，IF 0.75 約 113 TSS，0.80 是 128，0.85 就到約 145。強度只多了一成多，負荷卻多了將近三成。

各數值大致對應#

  • < 0.65：恢復騎，0.6 或更低都好
  • 0.65–0.75：有氧耐力長騎（Z2）
  • 0.75–0.85：節奏騎；含熱身、緩和的整堂甜蜜點（Sweet Spot，約 FTP 的 88–94%）課，也常落在這附近
  • 0.85–0.95：整堂的閾值或 VO2max（最大攝氧量）間歇課（含組間休息）、2.5 小時以上的公路賽
  • 0.95–1.05：約一小時的計時賽（多數業餘車手的 40 km）、較短的公路賽與繞圈賽
  • > 1.05：明顯短於一小時的全力賽事，例如 15 km 左右的短程計時賽、二十分鐘上下的爬坡賽

這是實務上的對照，不是生理定律。Coggan 公布的原始對照表，前面幾格都比我高一階：0.75 以下都算恢復騎、0.75–0.85 算耐力騎，節奏騎放在 0.85–0.95。我的分法沿用站上其他文章的說法（恢復騎低於 0.65、Z2 長騎 0.65–0.75），大致對得上功率區間的 Z1（低於 FTP 的 55%）和 Z2（56–75%）；整趟的 IF 通常比你設定的區間略高一點，因為起步、小坡都會把 NP 推高。我也刻意抓嚴一點，因為門診裡多數業餘車手的問題，正是輕鬆日不夠輕鬆。

四個實務用法#

一、檢查恢復日有沒有真的恢復。 恢復騎的 IF 最好在 0.6 左右或更低，最多別超過 0.65。超過 0.7，那不是恢復，是低強度訓練。幾次紅綠燈的猛起步、一段硬踩的小坡，就足以把 NP 推高。

二、確認長騎是不是真的長騎。 有氧長騎應該落在 0.65–0.75。被同伴帶到 0.8 的「長騎」，回來很累，買到的卻是另一種東西。

三、比賽後回頭校正 FTP。 Coggan 的經驗法則是：一場約一小時的比賽，IF 超過 1.05，往往代表你的 FTP 其實比設定值高。反過來，一小時全力計時賽只有 0.90，可能是 FTP 設太高、配速出問題，也可能是天氣太熱、前幾天太累，或是趴在計時把上本來就踩不出一般騎姿的功率。

四、預估一趟課表的負荷。 例如今天想騎 90 分鐘、把 TSS 控制在 80 左右，IF 就要抓在 0.73 上下（1.5 × 0.73² × 100 ≈ 80）。排課前先定好今天的 IF 目標，等於先決定了今天要付多少帳。

三個常見的誤會#

「IF 越高，代表練得越紮實。」 IF 要對上這趟的目的，不是越高越好。如果你一週每趟都落在 0.80–0.85，就是典型的灰色地帶：輕鬆日不夠輕鬆，辛苦日又不夠辛苦。

「整堂課 IF 0.85，所以我騎了 85% 強度。」 整堂的 IF 會被熱身和組間休息稀釋。間歇有沒有達標，要看每一組的區段平均功率。

「IF 一樣，就一樣累。」 IF 只說強度，不說時間。1 小時 IF 0.85 約 72 TSS，4 小時同樣的 IF 就是 289 TSS，完全不同量級。

強度係數看不到的東西#

分母錯，全部錯。 FTP 本身就是估計值。Borszcz 等人 2019 年在 15 位車手身上，比較 20 分鐘測試推算的 FTP 和實驗室測得的最大乳酸穩定狀態（血乳酸還能維持平穩的最高強度），平均很接近，但個別車手可能差到將近一成。FTP 也會隨季節漂移，建議每 4～8 週確認一次。上面的例子若把 FTP 誤設成 230 W，IF 會變成 0.91、TSS 約 167：FTP 少設 8%，負荷就被高估將近兩成。

資料品質。 功率計的各種誤差，NP 那篇整理過，它們會原封不動傳到 IF。IF 特有的陷阱是分子和分母來自不同設備：拿訓練台測的 FTP 去算戶外騎乘，誤差就混進來了。滑行的 0 瓦算不算、停紅燈有沒有自動暫停，也會讓同一趟騎乘在不同軟體上的數字不一樣。二十分鐘以內的短騎，NP 本身就不太可靠，IF 也跟著失真。

環境與身體狀態。 高溫、高海拔、沒睡飽時，同樣的 IF，身體付出的代價更高，但 IF 不會告訴你這件事。

物理治療師的角度：同樣的 IF，身體付的帳不一樣#

運動科學把訓練負荷分成兩部分：你做了什麼（外部負荷），以及身體因此承受了多少（內部負荷）。Impellizzeri 等人 2019 年的評論重新釐清了兩者的定義，提醒別混為一談。IF 量的是前者。值完大夜班、工作壓力爆表的那一週，IF 0.75 的騎乘，可能比平常 IF 0.85 的那趟還累。

膝蓋也一樣。功率等於踩踏扭力乘以轉速：同樣 200 W，迴轉速 60 rpm（每分鐘 60 圈）時每一下要出的力，比 90 rpm 多出 50%。IF 一模一樣，但對膝蓋前側比較敏感的人，用重齒比慢慢磨上坡，往往就是隔天開始痛的那一趟。所以看傷後車友的資料，我一定把迴轉速和 IF 一起看。

傷後回到車上，我常把 IF 當「天花板」：前幾週先壓在 0.70 以下，先加時間、再加強度，並看隔天早上症狀有沒有回到平常。四十歲以上的車手，兩次高 IF 的課之間，我通常也會多留一天。但我不會用某個 IF 或 TSS 數字預測你會不會受傷；Impellizzeri 等人 2020 年的評論直言，目前沒有證據支持用負荷數字精準調整訓練來預防受傷。數字幫我們記帳，判斷還是要看人。

強度係數 IF 超過 1.0，是不是代表 FTP 設錯了？#

不一定。FTP 對應的是約一小時的強度，所以短於一小時的全力騎乘，IF 超過 1.0 很正常，二十分鐘的爬坡賽到 1.05 以上也合理；起伏很大的繞圈賽，NP 也會被頻繁加速推高。真正該懷疑 FTP 的，是一場約一小時、全力且配速平穩的比賽，IF 還超過 1.05，那就該重測了。

強度係數 IF 和 TSS 有什麼不同？#

IF 回答「多硬」，TSS（訓練量分數）回答「多重」。IF 只看強度，TSS 把強度和時間合在一起：TSS ＝ 時數 × IF² × 100。所以 30 分鐘 IF 0.95 的短課約 45 TSS，比 3 小時 IF 0.65 的輕鬆長騎（約 127 TSS）小得多，但兩者刺激的東西完全不同。兩個數字要一起看。

強度係數 IF 和心率，訓練時該看哪一個？#

兩個都看，因為它們量的東西不同。IF 是你輸出了什麼，心率是身體怎麼回應。心率會受高溫、脫水、咖啡因和睡眠影響，反應也比功率慢；功率計只記錄你踩出了多少，不管你今天狀況好不好。最有用的是互相對照：同樣 IF 的騎乘，心率明顯比平常高，常見原因是太熱、脫水、沒睡飽或快生病了；反過來，心率拉不上去、腿卻特別沉，往往是累積疲勞的樣子。只要心率和感覺跟平常對不上，那天就該收手。

沒有功率計，能算強度係數 IF 嗎？#

嚴格來說不行，IF 需要功率資料。用速度和坡度推估的「估算功率」（例如 Strava 在沒有功率計時顯示的數字）受風、路面和體重影響很大，拿來算 IF 參考價值有限。比較實際的替代方案是心率，或騎完用 0～10 分替整趟的費力程度打分數（自覺費力，RPE）。這個分數和 IF 一樣只看強度、不看時間；乘上分鐘數就變成負荷，那是 TSS 那篇談的 session RPE。

鐵人三項的自行車段，強度係數 IF 該抓多少？#

常見的建議是：全程鐵人（180 km）大約 0.70–0.78，半程（90 km）大約 0.75–0.85。騎得越久的人要抓得越低，因為下車還要跑一場全馬或半馬。我常看到的失敗模式，是自行車段 IF 太高，跑步前半就撐不住。比賽的 IF 目標，最好先在長距離的騎跑連續訓練裡試過。

最後，讓數字回到它的位置#

IF 是一支很好用的溫度計：它讓「今天騎得多硬」從感覺變成可以比較的數字。但溫度計不會替你決定要不要出門。把 FTP 設準、資料顧好，再配上心率、睡眠和身體的感覺一起看，它才真正幫得上忙。

時間會騙人，距離也會。IF 直接告訴你，這趟騎乘離你的一小時極限有多近。
